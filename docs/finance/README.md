# Encova Finance

A restricted PKR accounting extension to the existing Encova Workspace. The supplied document describes the target system; it does not describe current functionality.

Start with [progress](progress.md), [repository assessment](repository-assessment.md), [decisions](decisions.md), and [the 48 milestones](planning/milestones.md). The original ERP roadmap remains separate.

F01–F10 are implemented and locally accepted: restricted ownership/setup, exact amounts, ordinary journal engine/lifecycle, dated core fixture, shared registers/drawers, parties and cash mappings. [Focused delivery report](delivery-F06-F10.md) and [exact verification](testing/F06-F10-results.md) distinguish working scope from later invoices/payments/statements/closing. No hosted finance migration/grant, real seed or launch occurred; finance remains disabled live.
