# Encova Finance

A restricted PKR accounting extension to the existing Encova Workspace. The supplied document describes the target system; it does not describe current functionality.

Start with [progress](progress.md), [repository assessment](repository-assessment.md), [decisions](decisions.md), and [the 48 milestones](planning/milestones.md). The original ERP roadmap remains separate.

F01–F03 cover assessment, documentation/feature gating and the access foundation. F04 adds controlled ownership, owner-only access changes, recipient-accepted transfer, fresh authentication and database protections; final publication is tracked in progress.md. F05 adds retained chart/period setup and exact PKR validation; ledger/posting and financial workflows remain pending. No live migration, owner grant, real financial import or finance launch has occurred.
