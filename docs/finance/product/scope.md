# Scope

Target: PKR accrual accounting for a service company: ledger, invoices/credits/receipts, bills/payments/advances, cash transfers/reconciliation, funding/loans, investments, assets, project finance, budgets, statements, dated opening/closing and restricted documents/exports.

Initial delivery: F01–F03 repository assessment, feature gate, shared current-account/grant checks, separate restricted audit schema, setup/status screen and concrete read-only status API. No accounting source is posted and no money total is represented.

Excluded: multi-currency, bank/trade execution, bank synchronization, inventory, automated payroll/tax filing and any claim of audited/statutory compliance. Ordinary ERP project/people/notifications stay free of financial fields.
