# F25 — Fixed asset register linked to posted purchases

## Goal
Register equipment against existing posted cost without recognizing the purchase twice.

## Task checklist
Implemented and locally verified. This completes the requested F16–F25 engineering scope.

## Completed work
Private versioned equipment register with tag, description, location/custodian, one real purchase FK, immutable source/account/cost snapshot, service date, useful life/residual, straight-line method, explicit pending/confirmed first-month convention, accumulated-depreciation and disposal fields. Bill/paid-expense ASSET lines and fixed-asset noncash-capital/founder-outlay sources are eligible. Actual original GL less source credits/reversals determines available net cost; recoverable input tax is excluded. Source allocations are serialized and deferred journal/source checks block later credits or funding reversals that would understate linked assets. Registration and VOID create no journal/payment/AP event. Unused VOID preserves source/history and releases allocation; metadata changes are versioned. Source/cost corrections require retained VOID and a new registration. First month stays pending until company confirmation; no depreciation/disposal charge is generated. See [asset rules](../../accounting/assets.md).
